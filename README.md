# JASPR-Lab/.github

Organization-wide defaults for [JASPR-Lab](https://github.com/JASPR-Lab).

| Path | Purpose |
|---|---|
| `profile/README.md` | Public profile shown on the org page |
| `.github/ISSUE_TEMPLATE/` | Default issue templates for any org repo without its own |
| `.github/PULL_REQUEST_TEMPLATE.md` | Default PR template for any org repo without its own |
| `TEMPLATES.md` | Which `repo-template` variant to use for which kind of project |

GitHub only uses these defaults for repos that don't have their own file of the
same type. A repo with its own `.github/ISSUE_TEMPLATE/` folder ignores this
repo's issue templates entirely.

This repo must stay **public** for the defaults and profile to work.
